# Slides

Presentation walking through the two-workflow release model, the version gating mechanism, and a live demo of the workflows running in this repo.

## Setup

The slides use [presenterm](https://github.com/mfontanini/presenterm), a terminal-based presentation tool.

Install via [GitHub releases](https://github.com/mfontanini/presenterm/releases) or homebrew:

```bash
brew install presenterm
```

## Running

From this directory:

```bash
presenterm workflow-demo.md
```

## Screenshots

Screenshots referenced in the slides should be placed in the `assets/` directory. See the image references in `workflow-demo.md` for the expected filenames.
